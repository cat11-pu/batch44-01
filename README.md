# GSB Bugfix Task
## 题面
关卡美术改成边改边看之后，编辑器里贴图经常还是上一版，重启一次才正常，一天要重启十几回，进度全被拖住。改完贴图引用没更新，场景里还是旧图；删掉的资源句柄失效，物体直接变成粉色；同时改材质和贴图，重载顺序错，材质引用旧贴图；重载时正在渲染，读到半加载的资源，画面闪一下黑；材质依赖的 shader 和贴图没有级联重载；保存两次触发两次重载，第二次失败后状态脏；重载失败没有回退，原始资源也被卸载；大小写不同的路径被当成两个资源；打包后的压缩资源读原始文件失败；重载后 GPU 资源没释放，显存一路涨；场景引用按路径存，重命名后引用全断，只能手工找回；监视器递归监听日志目录，触发重载风暴。asset_hot_reload_watch.py 的 AssetHotReloadWatch 管监视、依赖图、原子切换和句柄代际，编辑器和打包运行时共用同一套句柄表。监视事件、依赖图和切换结果要能按资源查，粉模时一眼看出是谁先卸载的。两条硬要求，编辑器崩溃也算失败：重载必须整组原子切换，资源和依赖半切换按 HOTRELOAD_PARTIAL 失败；重载失败必须保留上一份可用资源，卸载后无回退按 HOTRELOAD_LOST 失败，崩溃重启也要能恢复到上一份。第三条是同一资源两百毫秒内的重复变更必须合并，风暴按 HOTRELOAD_STORM 丢弃。下周进冲刺，监控面板要有重载成功率和耗时，这版要给全公司美术用，编辑器不能再这么折腾。

## 运行方式

```bash
python -m pytest tests -q
```

# GSB Bugfix Task
## 题面
周四团本重置后，公会里三十多号人分别卡在不同的进度上，团长把每一处对不上的地方都截了图发到群里。同一首领一晚上掉两次装备，锁定记录根本没写进去；队长有进度队员没有，进本后队员被传到门口，治疗只能在门外等；重置按 UTC 零点算，国服玩家周一早上还算上一周，白白少打一天；英雄和普通难度共用同一个锁定编号，打了普通就占掉英雄次数；退队再加入新队伍继承旧进度，掉落却按新队伍重新算；锁定按角色名存，改名以后进度直接消失；十人和二十五人模式共用编号，十人打完二十五人进不去，团长只能临时拆团；中途补位的玩家被写成全通，本周什么都拿不到；延长锁定把已经过期的记录也一并延长，下周又少一次；两个队伍同时进本，各自创建了不同的锁定编号，掉落互相覆盖；转服后锁定记录没跟着迁移，新服显示全通；击杀事件重复上报，首领计数加二，第二个首领直接跳过。raid_lockout_binder.py 的 RaidLockoutBinder 管编号、进度、重置和延长，进度表要能按角色和团队两个维度切开。三条硬线：同一编号下同一首领只能记一次击杀，重复按 LOCK_DUP_KILL 幂等丢弃，奖励不得二次发放；难度和人数规模必须参与编号生成，跨难度复用按 LOCK_SCOPE_MISMATCH 拒绝；重置必须原子完成，中断留下的半重置进度按 LOCK_RESET_PARTIAL 回滚。三条线任何一条不满足，本周进度一律作废重算。明晚八点开荒，进度表必须先对得上。


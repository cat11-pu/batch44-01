# GSB Bugfix Task
## 题面
主城石墙换上新材质以后，玩家贴着墙走时砖缝会跟着相机一起扭，斜着看整面墙像被抹开的水彩。斜视墙面时贴图沿视线方向拉伸，砖缝变成一道道竖条；深度步进用固定步长，近处精度不够，凹凸边缘全是锯齿；掠射角下 UV 偏移越界，采样到旁边砖块的花纹；高度图只存单面深度，背光墙面出现穿透的小洞；自阴影复用同一次步进结果，阴影方向和主光相反；mip 选择按基础 UV 算导数，不按偏移后的坐标，远处一直闪；多层视差的层间权重硬切，过渡带上出现台阶；高度图八位量化，斜坡上出现一圈圈阶梯纹，近景截图直接不能用；法线贴图和视差方向相反，高光位置和凹凸对不上；视差偏移按世界坐标算，物体一转整个凹凸错位；步进次数固定，大角度时直接穿透到墙后；相机移动时凹凸边缘抖动，像在水里游泳。parallax_occlusion_mapper.py 的 ParallaxOcclusionMapper 管深度步进、UV 偏移和自阴影，高度图与法线图共用一套切线空间。高度图、法线图和切线基要一起校验，方向和尺度对不上直接判材质配置错误。三条硬门禁：步进必须在深度层内收敛，越界采样按 POM_UV_ESCAPE 失败；自阴影必须与主光方向一致，反向或漏光按 POM_SHADOW_SIGN 失败；偏移后的纹理导数必须重算并用于 mip 选择，按基础 UV 取 lod 导致闪烁按 POM_LOD_DERIV 失败。材质组今晚要出对比图。这版材质要上主机认证，贴墙走不能再看到扭动。


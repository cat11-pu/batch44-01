# GSB Bugfix Task
## 题面
CI 沙箱接入 Landlock 后，研究员用一个继承下来的文件描述符读到了宿主机的构建密钥。构建镜像里还带着上一轮没清掉的临时密钥。规则集只处理读和执行，写、截断和引用权限完全没限制；路径规则挂在普通文件上，内核对目录的约束根本没建立；继承的打开文件描述符绕过路径限制，直接读原文件；规则在读取配置和密钥之后才生效，敏感数据已经进内存；叠加第二个规则集时把第一个的允许范围又扩大；启用前没有设置禁止提权标志，子进程可以重新执行；通过 /proc/self/fd 的魔法链接跳出根目录；空允许集合被当成拒绝，正常构建全部失败；规则生效前创建的线程不在约束范围内；内核 ABI 不支持所需权限位时静默降级；只限制文件系统，网络和端口规则完全缺失；文件权限和 umask 允许写入，规则却没覆盖该路径。landlock_ruleset_builder.py 的 LandlockRulesetBuilder 负责规则构建、ABI 协商和进程约束。ABI 缺少必需权限位时必须失败关闭并报 LANDLOCK_ABI_UNSUPPORTED；执行前必须关闭或重新校验所有继承的文件描述符，泄漏记 LANDLOCK_FD_LEAK；规则必须覆盖写、截断、引用和网络策略，缺失按 LANDLOCK_INCOMPLETE 拒绝启动，并输出缺失的权限位。第三方构建任务每天几万个，沙箱破了等于把密钥送人，平台组要求今晚先停掉高风险构建。

## 运行方式
```bash
python -m pytest tests -q
```

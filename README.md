# GSB Bugfix Task
## 题面
宠物繁殖开放跨服配对以后，稀有幼崽的成交价一周翻了三倍，工作室开始批量刷窝，经济组把繁殖日志和拍卖流水并在一起查。繁殖冷却按客户端时间算，改时区就能连配三窝；同一对宠物并发提交两次，两个请求各生成一窝，幼崽直接翻倍；父母在繁殖读条期间被交易或者放生，幼崽照样产出；近亲系数没有参与计算，兄妹配对和陌生配对的概率完全一样；稀有度随机用同一个种子，同一批号刷出来的幼崽一模一样；双人共养的宠物产崽只记一方，另一方连记录都查不到；每周繁殖次数上限扣的是账号不是宠物，换一只接着配；幼崽属性按父母当前等级继承，喂满级再配就能刷出超标个体；绑定宠物配出来的幼崽变成非绑定，直接进交易行；服务器重启后待领取的幼崽全部丢失，客服只能按截图补；宠物栏满的时候幼崽被吞掉，没有邮件也没有提示；同一窝幼崽点两次领取，背包里出现两只。pet_breeding_inherit.py 的 PetBreedingInherit 管配对校验、冷却扣减和幼崽归属，父母实例号、繁殖批次号和幼崽编号要能串成一条链。硬性要求三条：扣次数、进冷却和生成幼崽必须在同一事务里，缺一步按 BREED_PARTIAL 失败；幼崽归属按共养双方的账号各记一份，单方记录报 BREED_OWNER_LOST；随机结果只由服务端种子和批次号决定，客户端参数一律不参与，发现同种子复用按 BREED_SEED_REUSE 拒绝。经济组周五要对稀有幼崽的产出曲线，繁殖这块先封住。

## 运行方式

```bash
python -m pytest tests -q
```

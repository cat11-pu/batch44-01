# GSB Bugfix Task
## 题面
地形换成虚拟纹理以后，玩家骑马跑图时地面先是糊成一片，过两秒才慢慢变清楚，截图被顶上热帖。页面反馈晚一帧，快速移动时低清页一直不升级；LRU 把刚请求的页面当冷页淘汰，来回抖动；同一页被两个 mip 各请求一次，重复上传；UV 越界采样到相邻页，接缝处出现别人的图；常驻页被淘汰后地面直接花屏；反馈缓冲没清零，上一帧的请求残留到这一帧；页面表更新和采样之间没有屏障，读到半更新的表；页面预算超了就直接丢请求，没有排队；虚拟纹理和贴花共用页池，互相抢页，贴花多的地方地形先糊；加载失败的页返回纯黑而不是占位页，玩家看到一块块黑洞；相机切换后页面表没重建，整片地形错位；两路并发上传同一页，画面撕裂。virtual_texture_feedback.py 的 VirtualTextureFeedback 管页表、反馈、驻留队列和页池配额，地块切换与传送都要走同一套重建流程。页表、页池和驻留队列要能导出快照，糊片时按帧号就能定位是哪一页没驻留，以及它被谁挤掉。两条硬约束，任何一条破了都算回归：每帧请求的页面必须在预算内驻留或进入队列，静默丢弃按 VT_DROP 失败；页面表更新必须双缓冲并在一帧内原子切换，半更新按 VT_TABLE_TORN 失败。第三条是页面边界采样必须钳制在页内，越界按 VT_BLEED 失败，接缝处不许出现邻页花纹。驻留队列的长度也要能实时看到。下周开放新地图，跑图糊片必须先解决。

## 运行方式
```bash
python -m pytest tests -q
```

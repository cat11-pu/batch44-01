# GSB Bugfix Task
## 题面
新地图上线后，玩家发现墙上的弹孔会透到隔壁房间，美术把截帧发到群里，要求这周必须修掉。贴花投影只做了深度测试没做法线夹角判断，正对墙面的贴花会穿到背面物体上；贴在角色身上的纹身在跑动时来回滑动，采样用的是绑定姿态坐标；图集相邻两格之间没有留边，双线性采样把隔壁图案的颜色带过来；法线贴花的绿通道方向反了，弹坑看起来是凸的；贴花和地面在掠射角下互相闪烁，深度偏移按固定值给；视角衰减用世界法线算，侧着看直接消失；同一位置的多个贴花按固定顺序画，血迹永远盖住弹孔；图集满了以后覆盖最旧的格子，场景里还在引用那张图，图案整片错乱；透明表面上的贴花被当成不透明画，玻璃后面出现一块实心色块；屏幕空间贴花尺寸跟着分辨率走，四 K 下小一半；相机背后的贴花还在参与投影，转身时边缘闪一条亮线；高亮贴花被钳到一时色阶断开，泛光也带不出来。decal_projection_atlas.py 的 DecalProjectionAtlas 管投影矩阵、图集分配和绘制顺序，所有贴花按世界空间包围盒登记。验收卡三条：投影必须同时通过深度和法线夹角剔除，穿墙按 DECAL_LEAK 失败；图集每格四周留出至少四像素边距并强制钳制采样，渗色按 DECAL_BLEED 失败；贴花变换必须用世界空间逆投影，绑定姿态坐标只允许出现在蒙皮前的预处理里，用错按 DECAL_SPACE_MISMATCH 失败。美术给了十二张对照图，先按这十二条逐条过。

## 运行方式
```bash
python -m pytest tests -q
```

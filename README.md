# GSB Bugfix Task
## 题面
签到改版第一个月，论坛上全是断签截图，运营发现同一个账号在客服系统里被登记了三次补签。断签按协调世界时零点切日，东八区玩家晚上八点领完，过了四小时又算新的一天；补签卡用掉以后连续天数没有接上，界面还是从第一天算；断线重连或者重复提交能领两次当天奖励，邮件里躺着两份；月末三十一号到一号之间少判一天，整月全勤显示二十九天；维护跨过零点，全服集体断签，补偿邮件又按人发了两次；转服以后连续天数清零，客服只能手工补；奖励表月中改版，已经领过的天数对不上新表，第七天领到第一天的东西；连续七天循环的第八天，文案写第八天，发的却是第一天的奖励；补签没有次数上限，有人一次补了三十天；同账号两个角色各签各的，奖励拿双份；签到请求带着客户端日期，改系统时间就能提前领；赛季结束后还能补签上赛季的档位。login_streak_calendar.py 的 LoginStreakCalendar 管自然日判定、连续计数和奖励发放，区服时区和赛季日历由服务端配置下发。验收只认三条：每个账号每个自然日只能领取一次，唯一键由账号、区服和日历日组成，重复领取按 STREAK_DUP_CLAIM 拒绝；补签必须消耗补签卡且只能补最近七天，越界按 STREAK_MAKEUP_RANGE 拒绝；奖励档位按版本号取，历史记录不得随新表漂移，版本错配报 STREAK_TABLE_MISMATCH。明早十点要发全勤榜，签到账不能再错。

```bash
python -m pytest tests -q
```

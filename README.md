# GSB Bugfix Task
## 题面
转服功能开放第一天，客服就收到公会会长的联名信，说半个团的人转过去之后全部失联，公会频道只剩会长自己。转服后公会职位还在，公会编号失效，角色成了查不到的幽灵成员；邮件附件跟着角色走了，邮件列表没迁，附件成了孤儿；拍卖行挂单没下架，转服后同一件装备在原服挂着又在背包里；好友关系只保留单向，对方列表里还有你，你列表里没有对方；排行榜旧记录没清，新服出现同名两条，名次整体错位；转了三次都失败，费用扣了不退，客服只能手工补钻；角色编号在新服重新分配，所有社交引用全断；转服冷却按原服时间算，跨时区能绕过；账号下多个角色只能转一个，其余被锁住无法登录；迁移过程中源服还能写，两边同时打本；改名卡和转服同时提交，新名字冲突后回滚不完整；成就进度迁过去了，称号和坐骑没迁。character_transfer_migrator.py 的 CharacterTransferMigrator 管冻结、打包、写入和回滚，迁移清单要在开始前一次性列全。五类数据的迁移结果要分别落表，任何一类为空都要在报告里标红。三条底线：转服必须在源服冻结写入之后进行，双写按 XFER_SOURCE_LIVE 中止并回滚；必须覆盖角色、邮件、拍卖挂单、公会关系和社交引用五类数据，缺项按 XFER_INCOMPLETE 失败；失败必须全额退费且角色留在原服，半迁移状态按 XFER_ROLLBACK 处理。迁移清单在开始前要能导出给客服核对。周末大区合并前，转服通道要能安全关闭。

## 运行方式
```bash
python -m pytest tests -q
```

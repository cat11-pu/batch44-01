# GSB Bugfix Task
## 题面
室内关卡换成集群光照后，玩家在论坛贴出隔墙也能被火把照亮的截图，美术说灯完全不受控，关掉一半灯画面几乎没变化，验收直接打回。灯被分到错误格子，光漏进隔壁房间；集群网格用世界坐标划分，相机一动全错位；点光半径边界被裁掉，地面出现一圈硬边；灯一多每格列表溢出，后提交的灯直接消失；方向光也塞进集群，白白吃掉预算，夜里帧率掉到三十；相机移动后集群没重建，光照滞后一帧；深度切片按线性划分，远处精度不够出现断层；阴影灯和普通灯混在同一列表，采样时错位；半透明物体用了不透明集群，光照不一致；灯数统计按提交数而不是有效数，预算判断失真；网格分辨率固定，宽屏边缘格子过大；剔除用球心距离而没有用半径，大灯的边缘整圈丢失。clustered_light_binner.py 的 ClusteredLightBinner 管网格划分、灯分配和溢出策略，聚光灯和点光共用一套分桶。集群、灯列表和相机参数要能一起导出，漏光时按像素反查是哪一格没收到灯，以及被哪条规则丢掉。三条硬线：每盏灯必须出现在其影响范围覆盖的所有集群，漏分按 CLUSTER_LIGHT_LOSS 失败；集群容量溢出必须按影响度淘汰并保证最强灯可见，静默截断报 CLUSTER_OVERFLOW_SILENT，淘汰顺序要可复现；集群划分必须与当帧相机参数一致，滞后按 CLUSTER_STALE 失败。灯多的时候也不许出现整块黑。这周要过性能验收，隔墙漏光不能再有。

## 运行方式
```bash
python -m pytest tests -q
```

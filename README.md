# GSB Bugfix Task
## 题面
政务大厅上线可验证凭证后，有人拿一张过期的学历凭证也通过了闸机，还能反复出示同一份证明。大厅闸机接的是第三方核验端，凭证格式由省里统一发放，本地只能改校验逻辑。选择性披露的摘要不按签发者签名核对，改过的字段也能通过；持有者绑定证明缺失也接受，捡到凭证就能冒用；签发者信任列表允许自签证书，随便搭个服务就能发证；凭证状态列表不查或永久缓存，已吊销凭证一直有效；出示时的随机数没有绑定验证方和会话，整份证明可以重放；密钥绑定 JWT 的 typ 和 aud 都不校验；过期凭证在宽松时钟偏差下继续可用；请求只要姓名，返回却带出身份证号和住址；重复摘要指向同一字段也能通过，披露数量失控；签发者轮换密钥后旧凭证全失效，或者吊销的密钥继续可信；凭证类型与应用要求的 vct 不一致也放行；同一随机数窗口内重复提交被视为新请求。vc_presentation_verifier.py 的 VcPresentationVerifier 负责签名、持有者绑定、状态检查和披露字段裁剪。没有有效持有者证明的出示必须拒绝并记 VC_HOLDER_BINDING；吊销或暂停状态必须在新鲜度窗口内生效，否则报 VC_STATUS_INVALID；签发者不在信任列表必须拒绝并记 VC_ISSUER_UNTRUSTED，错误码要能直接给窗口人员解释。大厅每天几千人刷证，出了冒用就是行政责任，窗口人员已经开始手工登记，大厅经理要求今天给出说明。


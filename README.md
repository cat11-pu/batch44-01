# GSB Bugfix Task
## 题面
商城对账那天，财务发现充值流水和钱包余额差了七千多，运营先停掉了所有折扣活动，把最近的订单导成表格逐笔核。免费币和付费币塞在同一个余额字段，付费币被当赠送币花掉；扣款先改余额再写流水，进程崩溃后钱少了但查不到记录；同一商品并发下单，余额只扣一次，两件商品都发了；余额允许为负，透支之后充值直接抵掉，玩家白拿；大额充值超过三十二位整型上限，余额翻转成负数；汇率换算用浮点，来回换算几次就差出一枚币；活动币过期没清零，过期之后仍然能消费；退款只加余额不冲正原流水，对账时永远差一笔，财务已经贴了两天表；赠送币和购买币混合消费时顺序不对，玩家投诉扣错；流水号用毫秒时间戳，同一毫秒两笔直接冲突；跨服钱包同步延迟，玩家在两边各领一份；余额缓存和数据库不一致，重启后回跳到旧值。currency_wallet_ledger.py 的 CurrencyWalletLedger 负责扣减、入账、分桶和流水，退款和补偿也走同一条通道。不许破的三条：任何扣减都不得让余额为负，透支按 WALLET_INSUFFICIENT 拒绝且不留半条流水，也不许先记账后补扣；每笔变动必须有唯一流水号，余额要能由流水完全重放，重放不一致按 WALLET_LEDGER_DRIFT 失败；付费币与赠送币分桶记账，混用必须先按面值拆分，拆分错误报 WALLET_BUCKET_MIX。补丁今晚灰度，先保住付费币不被当成赠币花。审计下周一进场，账必须能对上每一分。


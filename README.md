# GSB Bugfix Task
## 题面
同一部片子在电视、手机和剪辑软件里颜色完全不一样，调色师把三个播放器的截图并排发到群里，肤色差了整整一档。BT.709 素材按 BT.601 解码，肤色整体发绿；有限范围被当成全范围，黑位发灰，白点溢出；HDR PQ 素材缺元数据，播放器按 SDR 渲染，整片发暗；分辨率切换时色彩矩阵没跟着换；传输函数标注错误，暗部细节整段丢失；YUV 转 RGB 用整型近似，天空出现色带；解码端和显示端各裁一次范围，对比度被压扁；旋转元数据和色彩元数据冲突，画面方向错；隔行素材场序标错，运动边缘拉丝；不同平台默认矩阵不一致，同片源两种颜色；转码之后色彩元数据被整段丢弃，下游只能按默认值猜；HDR 转 SDR 用固定曲线，高光全部死白。video_color_metadata.py 的 VideoColorMetadata 管矩阵、范围和传输函数，解码、转码和显示三端都要读到同一份标注。三端读到的矩阵、范围和传输函数要能打印出来对比，任何一端不同都算标注错误。两条硬约束：解码必须按容器标注的矩阵、范围和传输函数一致处理，任一错配按 COLOR_METADATA_MISMATCH 失败；有限与全范围只能映射一次，重复映射按 COLOR_RANGE_DOUBLE 失败。第三条是 HDR 转 SDR 必须走保留高光的色调映射，硬切按 COLOR_TONEMAP_CLIP 失败。交付方明天要片，三个播放器都要按同一份标注复测。颜色对不上就得重调。

## 运行方式
```bash
python -m pytest tests -q
```

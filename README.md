# GSB Bugfix Task
## 题面
家园系统开放第一周，玩家把家具摆到邻居地界的截图冲上了热帖，测试组连夜复现。旋转后的家具只按轴对齐包围盒判重叠，斜着摆的柜子角穿进墙里；两个人同时往同一个格子放同一件家具，两件都保存成功，回收时只退一件；摆放失败回滚不干净，家具从背包消失也没有回到仓库；碰撞只在放置那一刻检查，邻居后来加的隔断能直接穿过去；悬空家具下面支撑被收走，整排书架浮在半空；蓝图复制把限定家具一起复制，稀有度不校验；拆除返还按模板编号退，强化过的家具退成白板；地皮扩容后新格子没有继承权限，访客能进来改摆位；访客模式可以移动房主家具，退出还不还原；保存时只存了格子坐标没存朝向，重登家具全部朝一个方向；跨服参观加载的是对方上一版布局；撤销操作把已经拆掉的家具又恢复一份。housing_plot_placement.py 的 HousingPlotPlacement 管地块边界、碰撞和家具实例归属，家具的唯一实例号从获取那一刻生成，不允许按模板重建。三条不能破：放置必须同时通过地块边界、碰撞和归属校验，任一失败整单拒绝，不能落半件家具，违反按 HOME_PLACE_PARTIAL 失败；同一家具实例在任意时刻只能存在于背包、仓库、摆放三者之一，重复出现报 HOME_ITEM_DUP；拆除和回收必须按实例号原样返还，强化与绑定状态一起带回，模板化返还按 HOME_RECYCLE_LOSS 拒绝。美术明天要看家园宣传图，先把穿墙和复制这两类清掉。

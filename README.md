# GSB Bugfix Task
## 题面
夜战地图把动态光源翻了一倍以后，阴影开始整块整块地闪，主机认证的录屏里一眼就能看见，灯一多连地面都黑了。大尺寸阴影图把图集切碎，小灯分不到页；同一盏灯每帧重新分配页，阴影边缘一直在跳；页释放后没清引用，灯还在用旧页；动态阴影和静态阴影共用页，静态被覆盖；页对齐按一像素算，采样串到隔壁灯的阴影；视锥外的灯也分配页，预算白扔，真正需要的灯分不到；分配失败静默降级到无阴影，日志里什么都没有；灯删除之后页没回收，图集越用越碎；图集扩容后旧句柄失效，阴影全黑；阴影 pass 和主 pass 拿到的图集代际不一致；聚光灯按立方体阴影占了六页，预算直接爆掉，其他灯全被降级；优先级相同的灯按名字排序，帧间来回换。shadow_atlas_allocator.py 的 ShadowAtlasAllocator 管页分配、回收和优先级，点光、聚光和方向光的份额要分开算。图集分配表、灯清单和优先级要能一起导出，闪烁时按灯编号查到每一次换页，谁抢了页也要写清楚，别只留一句失败了。三条硬门禁，任何一条不过都不许送审：同一盏灯在其生命周期内页分配必须稳定，帧间跳页按 SATLAS_THRASH 失败；页边界必须留边距并在采样时钳制，串灯按 SATLAS_BLEED 失败；分配失败必须记录并按优先级降级，静默失败报 SATLAS_SILENT_DROP。认证版本下周送审，图集占用率要能打点到监控。阴影闪烁必须清零。

## 运行方式
```bash
python -m pytest tests -q
```

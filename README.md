# GSB Bugfix Task
## 题面
平台上线自动响度归一之后，观众投诉片头正常、正片突然炸耳朵，广告段又轻得听不见，投诉单一天破了三百。整轨积分响度达标，但广告段瞬间过响；真峰值超过零 dBFS，母带直接削波；门限实现错误，静音段把整体增益拉高；五点一声道按单声道求和，响度虚高六 dB；归一化之后又走一遍限幅，响度被二次改变；采样率不同导致 K 加权系数用错；实时流按块归一化，块与块之间增益跳变；已经归一化的内容被重复归一化，越做越轻；元数据里写的响度和实际测量值不符，平台直接判不合规；三秒以内的短节目积分窗不足，结果离谱；立体声与单声道互转后响度差三 dB；淡入淡出段被计入积分，拉低整段，安静片头被整体抬响。loudness_lufs_normalizer.py 的 LoudnessLufsNormalizer 管测量、门限和增益应用，实时流和离线文件共用同一套计量。逐段响度、真峰值和门限命中要能一起出表，交付时按节目段落分别签字，任何一段超标都要重做。三条硬线：积分响度必须按 ITU-R BS.1770 的 K 加权和双门限计算，偏差超过零点一 LU 按 LOUDNESS_METER_DRIFT 失败；真峰值必须留至少负一 dBTP 余量，削波按 LOUDNESS_CLIP 失败；增益必须整段一次性应用，块间跳变按 LOUDNESS_GAIN_STEP 失败。下个月要过平台审核，报告要能给出逐段曲线和门限命中数。响度报告得能复现。

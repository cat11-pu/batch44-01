# GSB Bugfix Task
## 题面
直播推流把四十四点一 k 的伴奏转成四十八 k 之后，乐手在监听里听出整体音高偏高，连着换了三台机器、两套声卡，问题都复现。四十四点一 k 转四十八 k 之后整体音高偏移，人声明显发尖；长时间播放时钟漂移，十分钟后和画面差两百毫秒；抗混叠截止频率写死，八 k 输入出现明显混叠；多声道各自重采样，相位不一致，声像左右漂；缓冲区边界滤波器状态被重置，每次回调咔哒一声，安静段落特别明显；整数倍重采样用浮点累加，误差随时间累积；变速播放时采样率跟着变，音调也跟着变；单声道上混立体声只复制左声道，右声道静音；切到蓝牙设备后采样率没重建，播放速度变了；重采样引入的延迟没有补偿，和视频对不上；三十二帧的短缓冲下滤波器反复重置，全是噪声；静音段被重采样成底噪，安静场景一直嗡嗡响。audio_src_resampler.py 的 AudioSrcResampler 管比率、滤波器和缓冲衔接，设备切换和变速播放都要复用它。输入输出比率、滤波器状态和累计漂移要能实时读出，长播一小时偏差不许超过一个采样。三条硬要求：重采样必须保持滤波器相位连续，跨缓冲不连续按 SRC_DISCONTINUITY 失败；输出采样数必须与输入时长严格匹配，累计漂移超过一个采样按 SRC_DRIFT 失败；抗混叠截止必须随输入输出比率调整，混叠分量高于负六十 dB 按 SRC_ALIAS 失败。下周要接专业声卡，录音棚那边周五要试听。时钟这块必须先稳住。

## 运行方式

```bash
python -m pytest tests -q
```

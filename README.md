# GSB Bugfix Task
## 题面
战斗特效加上体积烟之后，半透明的排序问题在截帧里全暴露了，烟总是压在火前面，爆炸中心反而看不见。半透明粒子互相遮挡顺序错，远处的烟盖住近处的火；权重函数在深度接近时饱和，远处物体直接消失；OIT 累积缓冲没清零，上一帧残影拖一条；开 MSAA 后解析只用单采样，边缘全是锯齿；乘法混合和加法混合的材质被当成普通透明；半透明物体写了深度，后面的透明全被剔；累积缓冲用十六位浮点，亮度高时溢出；解析 pass 放在前向之后但深度测试还开着；排序只按距离没考虑材质，同距离互相闪；折射材质在 OIT 里被当不透明直接挡住背景，水面下的鱼全看不见；视锥外的粒子仍然写缓冲，浪费带宽；分屏两个相机共用一份 OIT 缓冲，画面串，右边玩家的血条跑到左边。transparency_oit_resolve.py 的 TransparencyOitResolve 管累积、权重和解析，粒子和半透明模型走同一条队列。累积、解析和排序三份数据要能对齐到同一帧号，错位时能指出是哪个 pass 写坏了，以及对应的材质编号。两条硬要求：累积与解析必须成对清零，残影按 OIT_RESIDUE 失败；权重函数必须保证任意深度差下能量非零，饱和丢片按 OIT_ENERGY_LOSS 失败。另有一条是加法与乘法混合材质必须走独立解析路径，混入透明路径按 OIT_BLEND_KIND 失败。截帧对比要能复现到同一帧。新版本特效量翻倍，排序这块不能靠运气。

## 运行方式
```bash
python -m pytest tests -q
```

# GSB Bugfix Task
## 题面
语音开黑改成 Opus 之后，弱网玩家的队友听他们说话像卡带，一句话重复三遍才往下走，团战指挥直接断线。抖动缓冲固定两百毫秒，网络好的时候延迟也下不来；丢包后隐藏算法一直重复最后一个音，听着像跳针；连续丢五帧以上直接静音，恢复时爆一声；时间戳回绕没处理，缓冲重排把新包排到后面；乱序包直接丢弃，没有按序列号重排；静音检测把舒适噪声当成丢包，一直触发隐藏；抖动估计用平均值，突发抖动时缓冲不够用，团战一开就断；丢包之后解码器状态没同步，后面几帧全错；双声道只隐藏左声道，右声道直接断，戴耳机听像偏瘫；缓冲伸缩时播放速率突变，音调跟着变；带内 FEC 的冗余包收到了却没用；会话结束时缓冲里还有没播完的音频，下一通开头先放出半句。opus_jitter_conceal.py 的 OpusJitterConceal 管缓冲、重排和隐藏，解码器状态要能跨丢包恢复。缓冲深度、丢包序列和隐藏次数要能按会话导出，卡顿时先看这三组数，再谈是不是网络问题，证据要留全。两条硬门禁，压测里必须逐条过：缓冲深度必须随抖动自适应且有上限，上限还要能按场景配置，固定延迟按 JITTER_FIXED 失败；连续丢包必须渐隐并平滑恢复，爆音或无限重复按 PLC_GLITCH 失败。还有一条是重排必须按扩展序列号处理回绕，回绕错判按 JITTER_WRAP 失败。下周电竞比赛要用这套语音，比赛前要跑一轮弱网回归。卡带不能再出现。

## 运行方式
```bash
python -m pytest tests -q
```
